# Dale al Rec

App web gratuita para crear guiones de radio escolar. Sin servidor, sin IA integrada y sin claves.

- Elige curso, temática y duración.
- Obtén la escaleta y el guion, para copiar o imprimir.
- Temática libre: botón «Copiar prompt» para usar tu propia IA.

Los textos están en `data/*.json` (un archivo por temática) y están incrustados en `index.html`. Los textos son orientativos: revisa los datos antes de emitir.
